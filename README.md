В файле requirements.txt перечислены все внешние зависимости исполняемых тестов для удобной установки одной командой.

Файл conftest.py содержит фикстуры, необходимые для запуска тестов.

Файл config.py содержит ссылки на ручки.

Файл data.py содержит данные, необходимые для тестирования.

Файл helpers.py содержит вспомогательные функции для работы тестов.

Файл api_methods.py в нем собраны функции, которые непосредственно необходимы для работы с ручками.

В директории tests собраны все необходимые тесты, а именно:
test_courier_create.py - тесты, связанные с созданием курьера;
test_courier_delete.py - тесты, связанные с удалением курьера;
test_courier_login.py - все,что связано с логином курьера;
test_orders_accept.py - тесты, связанные с обработкой заказа;
test_orders_create.py - тесты, связанные с созданием заказа;
test_orders_get.py - тесты, связанные с получением данных заказа.

Директория allure_results содержит JSON-файлы с результатами выполнения тестов для генерации отчета.
